🛍️ 08. លក្ខណៈបច្ចេកទេស Showroom Technical Spec

មជ្ឈមណ្ឌលឯកសារ / ឯកសារបច្ចេកទេស / លក្ខណៈបច្ចេកទេស Showroom

ឯកសារលក្ខណៈបច្ចេកទេសបន្ទប់តាំងបង្ហាញទំនិញឌីជីថល និងពាណិជ្ជកម្មតាមការសន្ទនា #

DIGITECHKH Digital Showroom & Conversational Commerce #

ឯកសារនេះកំណត់អំពីស្ថាបត្យកម្ម មុខងារ លំហូរការងារ និងយុទ្ធសាស្ត្រនៃការបង្កើត «បន្ទប់តាំងបង្ហាញទំនិញឌីជីថល (Digital Showroom)» សម្រាប់ក្រុមហ៊ុនអតិថិជន ដោយគ្មានប្រព័ន្ធកាត់ប្រាក់ស្មុគស្មាញ (No Direct Checkout Friction) និងជំនួសមកវិញនូវប្រព័ន្ធលក់តាមការសន្ទនាផ្ទាល់ (Conversational Commerce) តាមរយៈប៊ូតុង «ទាក់ទងអ្នកលក់»។

1. ទស្សនវិជ្ជា និងមូលហេតុស្នូលនៃការរចនា #

1.1 បរិបទ និងឥរិយាបថទិញទំនិញនៅកម្ពុជា #

  • ការស្ទាក់ស្ទើរលើការកាត់កាតធនាគារ៖ អតិថិជនកម្ពុជាជាង 80% មិនចូលចិត្តកាត់កាតធនាគារទិញទំនិញភ្លាមៗលើគេហទំព័រដោយមិនបាននិយាយជាមួយមនុស្សពិតប្រាកដឡើយ។
  • ទម្លាប់ចរចា និងបញ្ជាក់ស្តុក៖ មុននឹងសម្រេចចិត្តទិញ អតិថិជនតែងតែចង់ដឹងថាតើទំនិញមានក្នុងស្តុកជាក់ស្តែងឬទេ? អាចបញ្ចុះតម្លៃពិសេសបានប៉ុន្មាន? ដឹកជញ្ជូនដល់ផ្ទះដោយរបៀបណា?
  • ការលក់បែបអាជីវកម្មទៅអាជីវកម្ម និងទំនិញតម្លៃខ្ពស់៖ មុខទំនិញដែលមានតម្លៃមធ្យម ឬខ្ពស់ (ដូចជា គ្រឿងសំណង់ គ្រឿងអេឡិចត្រូនិច គ្រឿងសង្ហារិម សម្ភារៈការិយាល័យ ការបញ្ជាទិញដុំ) មិនអាចលក់ដាច់តាមរយៈការចុចកន្ត្រកទំនិញធម្មតាឡើយ គឺត្រូវការការប្រឹក្សាយោបល់ និងការចេញសម្រង់តម្លៃជាផ្លូវការ។

1.2 ដំណោះស្រាយរបស់ DIGITECHKH #

  • ដកចេញនូវឧបសគ្គនៃការបង់ប្រាក់ភ្លាមៗ៖ គេហទំព័រមិនបង្ខំឱ្យអតិថិជនបញ្ចូលព័ត៌មានកាត ឬទូទាត់លុយភ្លាមៗឡើយ។
  • ដាក់ប៊ូតុង «ទាក់ទងអ្នកលក់» លើគ្រប់មុខទំនិញ៖ អតិថិជនគ្រាន់តែចុចលើប៊ូតុងនេះ ព័ត៌មានទំនិញ (រូបភាព ឈ្មោះ កូដ តម្លៃ) នឹងរត់ចូលក្នុងការជជែកភ្លាមៗ។
  • ការបំលែងទៅជាការលក់ជាក់ស្តែង៖ បុគ្គលិកលក់ជជែកផ្តល់ព័ត៌មាន រួចចុចតែ 1 ប៊ូតុង «បង្កើតសម្រង់តម្លៃ» ឬ «ចេញវិក្កយបត្របាគង» ផ្ញើជូនអតិថិជនក្នុងបន្ទប់ជជែកនោះផ្ទាល់។

3. យន្តការលម្អិតនៃប៊ូតុង «ទាក់ទងអ្នកលក់» #

នៅពេលអតិថិជនចុចលើប៊ូតុង «ទាក់ទងអ្នកលក់» ប្រព័ន្ធនឹងដំណើរការជំហានដូចខាងក្រោម៖

  1. ការប្រមូលទិន្នន័យទំនិញ (Payload Extraction)៖
    • លេខកូដទំនិញ (Product ID / SKU)
    • ឈ្មោះមុខទំនិញ និងប្រភេទ
    • តម្លៃឯកតា និងរូបិយប័ណ្ណ ($ ឬ រៀល)
    • ស្ថានភាពស្តុកបច្ចុប្បន្ន (In Stock / Pre-order)
    • រូបភាពទំនិញខ្នាតតូច
  2. ការបង្ហាញផ្ទាំងជម្រើសសន្ទនា (Conversational Modal)៖
    • បង្ហាញរូបភាព និងព័ត៌មានសង្ខេបនៃទំនិញដែលអតិថិជនចាប់អារម្មណ៍។
    • ផ្តល់ជម្រើសទំនាក់ទំនង 3 ឆានែល ស្របតាមចំណង់ចំណូលចិត្តរបស់អតិថិជន។

4. ការវិភាគឆានែលទំនាក់ទំនងទាំង 3 #

ឆានែលទី 1៖ ការជជែកផ្ទាល់លើគេហទំព័រ (Web Live Chat) #

  • របៀបដំណើរការ៖ ផ្ទាំងជជែកអណ្តែតឡើងលើគេហទំព័រភ្លាមៗ។ អតិថិជនអាចសរសេរសំណួរបានភ្លាមៗដោយមិនបាច់ចាកចេញពីទំព័រ។
  • ចំណុចពិសេស៖
    • ប្រព័ន្ធភ្ជាប់កាតព័ត៌មានទំនិញចូលក្នុងបន្ទប់ជជែកដោយស្វ័យប្រវត្តិ។
    • បុគ្គលិកលក់អាចផ្ញើរូបភាព ប័ណ្ណសម្រង់តម្លៃ PDF និងកូដស្កេនបាគងចូលក្នុងបន្ទប់ជជែកបានផ្ទាល់។
    • ស្នើសុំលេខទូរស័ព្ទ ឬតេឡេក្រាមស្រាលៗ ដើម្បីធានាការទាក់ទងបន្តប្រសិនបើអតិថិជនបិទកម្មវិធីរុករក។

ឆានែលទី 2៖ ការភ្ជាប់ទៅកាន់តេឡេក្រាម (Telegram Deep Link) #

  • របៀបដំណើរការ៖ ប៊ូតុងភ្ជាប់ទៅកាន់តំណ https://t.me/company_bot?start=prod_1001 ឬគណនីផ្នែកលក់។
  • ចំណុចពិសេស៖
    • ត្រូវតាមទម្លាប់ប្រជាជនកម្ពុជាជាង 90% ដែលប្រើតេឡេក្រាមជារៀងរាល់ថ្ងៃ។
    • ប្រព័ន្ធស្វ័យប្រវត្តិបញ្ចូលសាររៀបចំស្រេច៖ «សួស្តី! ខ្ញុំចាប់អារម្មណ៍ទំនិញ [ឈ្មោះទំនិញ] កូដ [SKU] តម្លៃ [តម្លៃ]។ តើមានក្នុងស្តុកទេ?»
    • បុគ្គលិកលក់អាចបន្តជជែក និងផ្ញើឯកសារផ្លូវការបានយ៉ាងរលូន។

ឆានែលទី 3៖ ការហៅទូរស័ព្ទផ្ទាល់ (Direct Phone Call) #

  • របៀបដំណើរការ៖ បង្ហាញលេខទូរស័ព្ទផ្នែកលក់ (Cellcard / Smart / Metfone) ជាមួយប៊ូតុងចុចខលចេញភ្លាមៗសម្រាប់ទូរស័ព្ទដៃ។
  • ចំណុចពិសេស៖ ស័ក្តិសមបំផុតសម្រាប់អតិថិជនវ័យចំណាស់ ឬការទិញបន្ទាន់ដែលត្រូវការការសម្រេចចិត្តភ្លាមៗ។

5. លំហូរការងារពីការជជែក ទៅសម្រង់តម្លៃ និងវិក្កយបត្រ (Chat-to-Quote & Chat-to-Invoice) #

នេះគឺជាចំណុចខ្លាំងបំផុតដែលប្រព័ន្ធដទៃទៀតគ្មាន៖

  1. ការតភ្ជាប់ជាមួយប្រព័ន្ធលក់ខាងក្នុង៖ នៅពេលអតិថិជនចាប់ផ្តើមជជែក ប្រព័ន្ធនឹងបង្កើតទិន្នន័យអតិថិជនសក្តានុពលថ្មីមួយក្នុងម៉ូឌុលលក់ដោយស្វ័យប្រវត្តិ។
  2. ការចេញសម្រង់តម្លៃ 1 ចុច៖ បុគ្គលិកលក់គ្រាន់តែចុចប៊ូតុង «បង្កើតសម្រង់តម្លៃ» នៅលើផ្ទាំងជជែក នោះប្រព័ន្ធនឹងទាញយកទិន្នន័យអតិថិជន មុខទំនិញ និងតម្លៃចូលក្នុងទម្រង់សម្រង់តម្លៃភ្លាមៗ។
  3. ការអនុវត្តតម្លៃឌីណាមិក៖ បុគ្គលិកលក់អាចកែសម្រួលការបញ្ចុះតម្លៃពិសេស ឬកំណត់ការចូលរួមមុន (Down Payment) បានយ៉ាងរហ័ស។
  4. ការបង្កើតកូដស្កេនបាគង ខេអេចឃ្យូអរ ឌីណាមិក៖ នៅពេលសម្រង់តម្លៃ ឬវិក្កយបត្រត្រូវបានអនុម័ត ប្រព័ន្ធបង្កើតកូដស្កេនបាគងដែលមានចំនួនទឹកប្រាក់សុក្រឹត រួចផ្ញើជាសាររូបភាពចូលក្នុងបន្ទប់ជជែកភ្លាមៗ។
  5. ការទូទាត់ និងកាត់ស្តុក៖ អតិថិជនស្កេនបង់ប្រាក់តាមកម្មវិធីធនាគារណាក៏បាន → ប្រព័ន្ធផ្ទៀងផ្ទាត់ស្វ័យប្រវត្តិ → ប្តូរស្ថានភាពទៅជា «បានទូទាត់» → ចេញប័ណ្ណដឹកជញ្ជូន និងកាត់ស្តុកក្នុងឃ្លាំងភ្លាមៗ!

6. អត្ថប្រយោជន៍សម្រាប់ម្ចាស់អាជីវកម្ម និងក្រុមការងារលក់ #

  1. មិនបាត់បង់អតិថិជន៖ រាល់ការចុច «ទាក់ទងអ្នកលក់» ត្រូវបានកត់ត្រាទុក គ្មានការបាត់បង់ដូចការតាំងលក់ធម្មតាឡើយ។
  2. ការគ្រប់គ្រងទិន្នន័យកណ្តាល៖ ម្ចាស់អាជីវកម្មអាចមើលឃើញថាតើបុគ្គលិកលក់ណាខ្លះបានឆ្លើយតបអតិថិជនលឿន ឬយឺត និងបិទការលក់បានប៉ុន្មាននាក់។
  3. លុបបំបាត់ការក្លែងបន្លំ៖ បុគ្គលិកលក់មិនអាចលួចផ្ញើកូដស្កេនគណនីផ្ទាល់ខ្លួនបានឡើយ ពីព្រោះប្រព័ន្ធបង្កើតកូដបាគងចេញពីគណនីក្រុមហ៊ុនផ្លូវការដោយស្វ័យប្រវត្តិ។
  4. បង្កើនទំនុកចិត្តអតិថិជន៖ អតិថិជនមានអារម្មណ៍កក់ក្តៅ និងមានសុវត្ថិភាព ព្រោះបានជជែកជាមួយអ្នកលក់ពិតប្រាកដមុននឹងសម្រេចចិត្តបង់ប្រាក់។
