DIGITECHKH BMS - មេរៀនស្រង់ចេញ និងស្តង់ដារប្រៀបធៀបពីឯកសារយោងទាំង 17 (Reference Analysis & Delivery Benchmark) #

ឯកសារនេះចងក្រងនូវការស្រាវជ្រាវ ការអាន និងការវិភាគយ៉ាងស៊ីជម្រៅលើឯកសារគំរូចែកចាយកម្រិតសហគ្រាសទាំង 17 ឯកសារ (PDFs) ដែលស្ថិតក្នុងថត documentation/ (រួមមាន CCN, CamCyber POS និង ClassMaster Delivery Documents V2) ដើម្បីជាមូលដ្ឋានគ្រឹះក្នុងការរៀបចំប្រព័ន្ធ DIGITECHKH Business Management System (BMS) ឱ្យក្លាយជាប្រព័ន្ធគ្រប់គ្រងអាជីវកម្មកម្រិតកំពូល (Enterprise-Grade Quality)។

1. សេចក្តីសង្ខេបនៃការវិភាគឯកសារយោងទាំង 17 (Comprehensive Review of 17 Reference Documents) #

ក្រុមទី 1៖ គម្រោង CCN (Cambodia Council of Nurses - គណៈគិលានុបដ្ឋាកកម្ពុជា) — 4 ឯកសារ #

  1. 1- CCN - Overview - 160725.pdf (7 ទំព័រ)៖
    • បង្ហាញទិដ្ឋភាពទូទៅនៃប្រព័ន្ធគ្រប់គ្រងសមាជិកភាពគិលានុបដ្ឋាកកម្ពុជា។
    • កំណត់តួនាទីស្នូលចំនួន 4៖ សមាជិក (Member), ប្រតិបត្តិករថ្នាក់ខេត្ត (Provincial Operator), ប្រតិបត្តិករថ្នាក់ជាតិ (National Operator), និងអភិបាលប្រព័ន្ធ (System Admin)។
    • ម៉ូឌុលស្នូល៖ ការស្នើសុំប័ណ្ណថ្មី/បន្តសុពលភាព, ការផ្ទេរកន្លែងការងារ, និងការគណនាពិន្ទុ CPD តាមរយៈការធ្វើបទបង្ហាញ និងវគ្គបណ្តុះបណ្តាល។
  2. 2- CCN - Register and Renew License- 160725.pdf (13 ទំព័រ)៖
    • លំហូរការងារលម្អិតពីមួយជំហានទៅមួយជំហាន (Step-by-step Lifecycle) សម្រាប់ការចុះឈ្មោះ និងបន្តសុពលភាពអាជ្ញាប័ណ្ណ។
    • ដំណាក់កាលអនុម័តពីរថ្នាក់ (Two-tier Verification)៖ សមាជិកដាក់ពាក្យ -> ភ្ជាប់ឯកសារ -> បង់ប្រាក់ -> ប្រតិបត្តិករខេត្តត្រួតពិនិត្យ -> ប្រតិបត្តិករជាតិអនុម័ត -> បោះពុម្ពប័ណ្ណមាន QR Code ផ្ទៀងផ្ទាត់។
  3. 3- CCN - Presentation and Training- 140725.pdf (10 ទំព័រ)៖
    • លំហូរស្នើសុំធ្វើបទបង្ហាញ និងការចុះឈ្មោះចូលរៀនវគ្គបណ្តុះបណ្តាលដើម្បីបង្គ្រប់ពិន្ទុវិជ្ជាជីវៈ (CPD Points)។
    • បង្ហាញការភ្ជាប់ឯកសារភស្តុតាង និងការផ្តល់ពិន្ទុដោយស្វ័យប្រវត្តិក្រោយពេលប្រតិបត្តិករអនុម័ត។
  4. 4- CCN - Transfer- 140725.pdf (6 ទំព័រ)៖
    • លំហូរផ្លាស់ប្តូរកន្លែងការងារ ឬមន្ទីរពេទ្យ/គ្លីនិករបស់សមាជិក ព្រមទាំងការផ្ទៀងផ្ទាត់ឯកសារយល់ព្រមពីស្ថាប័នទាំងសងខាង។

2 Full Lifecycle Request & Approval Workflow (CCN) រាល់ប្រតិបត្តិការអាជីវកម្មទាំងអស់ត្រូវឆ្លងកាត់វដ្តជីវិតពេញលេញ៖ ស្នើសុំ (Draft) -> ត្រួតពិនិត្យ (Pending) -> អនុម័ត (Approved) -> អនុវត្ត/ទូទាត់ (Fulfilled/Paid) -> បិទបញ្ចប់ (Closed)។
3 Enterprise Dedicated Pages (ClassMaster & CamCyber) គ្មានការប្រើប្រាស់ Modal Dialog Pop-up សម្រាប់ Create/Edit/View ឡើយ។ គ្រប់ទម្រង់ទាំងអស់ជា Dedicated Full Page មានប៊ូតុងត្រឡប់ក្រោយស្តង់ដារ និង A4 Enterprise Print Layout។
4 3-Tier Delivery Verification (D-7, D-1, T-90 Checklist) ការរៀបចំបញ្ជីត្រួតពិនិត្យប្រព័ន្ធ DIGITECHKH BMS ត្រូវបានចែកជា 3 ដំណាក់កាល (D-7 Code Audit, D-1 Link & Form Freeze, T-90 Pre-Flight Verification)។
5 100% Strict Pure Khmer & English Numerals (Project Standard) រក្សាភាសាខ្មែរសុទ្ធសាធ គ្មានពាក្យអង់គ្លេសលាយឡំលើ UI និងប្រើប្រាស់លេខអង់គ្លេស (0-9) លើគ្រប់តួលេខទូទាំងប្រព័ន្ធ។

3. ផែនការផ្ទៀងផ្ទាត់តួនាទីម្តងមួយៗ (One-Role-at-a-Time Review Process) #

ដើម្បីធានាបាននូវគុណភាពកម្រិតខ្ពស់បំផុត និងមិនឱ្យមានការខកខាននូវព័ត៌មានលម្អិតណាមួយ យើងនឹងដំណើរការផ្ទៀងផ្ទាត់ និងកែលម្អប្រព័ន្ធតាមលំដាប់តួនាទីម្តងមួយៗ ដោយមិនប្រញាប់ប្រញាល់ឡើយ។ រាល់ពេលដែលតួនាទីមួយត្រូវបានអ្នកប្រើប្រាស់ត្រួតពិនិត្យ និងបញ្ជាក់យល់ព្រមរួចរាល់ ទើបយើងបោះជំហានទៅកាន់តួនាទីបន្ទាប់៖

  1. តួនាទីទី 1៖ ស៊ុបភើរ អភិបាល (Super Admin) ⬅ (កំពុងដំណើរការពិនិត្យ)
  2. តួនាទីទី 2៖ អភិបាលគ្រប់គ្រង (Admin / General Manager)
  3. តួនាទីទី 3៖ អ្នកគ្រប់គ្រងផ្នែកលក់ (Sales Manager)
  4. តួនាទីទី 4៖ បុគ្គលិកផ្នែកលក់ (Sales Executive)
  5. តួនាទីទី 5៖ អ្នកគិតលុយ (Cashier / POS Operator)
  6. តួនាទីទី 6៖ អ្នកគ្រប់គ្រងលទ្ធកម្ម (Procurement Manager)
  7. តួនាទីទី 7៖ អ្នកគ្រប់គ្រងស្តុក (Warehouse Manager)
  8. តួនាទីទី 8៖ បុគ្គលិកទទួល និងវេចខ្ចប់ទំនិញ (Warehouse Staff)
  9. តួនាទីទី 9៖ ប្រធានគណនេយ្យ (Chief Accountant)
  10. តួនាទីទី 10៖ គណនេយ្យករទូទាត់ (Accounts Payable / Receivable)
  11. តួនាទីទី 11៖ នាយកប្រតិបត្តិ (Executive / Auditor)
  12. តួនាទីទី 12៖ ផ្នែកគាំទ្រអតិថិជន (Customer Support)
