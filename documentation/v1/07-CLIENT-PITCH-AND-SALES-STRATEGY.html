យុទ្ធសាស្ត្រលក់ និងក្បួនសន្ទនាបញ្ចុះបញ្ចូលអតិថិជន #

DIGITECHKH Business Management System (BMS) #

ឯកសារនេះគឺជាសៀវភៅណែនាំយុទ្ធសាស្ត្រលក់ផ្លូវការ សម្រាប់ថ្នាក់ដឹកនាំ ក្រុមការងារលក់ និងទីប្រឹក្សាអាជីវកម្ម ក្នុងការចុះជួប ធ្វើបទបង្ហាញ និងចរចាជាមួយម្ចាស់អាជីវកម្មនៅកម្ពុជា ដើម្បីបិទការលក់ប្រព័ន្ធ DIGITECHKH BMS ប្រកបដោយប្រសិទ្ធភាពខ្ពស់បំផុត។

1. ការយល់ដឹងពីចិត្តសាស្ត្រ និងការឈឺចាប់របស់ម្ចាស់អាជីវកម្មនៅកម្ពុជា #

ដើម្បីលក់ប្រព័ន្ធបានជោគជ័យ អ្នកលក់មិនត្រូវនិយាយតែពីបច្ចេកវិទ្យានោះឡើយ ប៉ុន្តែត្រូវនិយាយចំពី «ការឈឺចាប់» និង «ការព្រួយបារម្ភពិតប្រាកដ» របស់ម្ចាស់អាជីវកម្ម៖

ការព្រួយបារម្ភកំពូលទាំង 4 របស់ម្ចាស់អាជីវកម្ម៖ #

  1. ការបារម្ភរឿងបាត់បង់លុយ និងស្តុក៖
    • ម្ចាស់អាជីវកម្មភាគច្រើនមិននៅកន្លែងលក់ 24 ម៉ោងទេ។ ពួកគាត់តែងតែសង្ស័យថាបុគ្គលិកអាចលួចលុយ លួចកែវិក្កយបត្រ ឬលួចយកទំនិញចេញពីឃ្លាំង។
  2. ការបារម្ភរឿងភាពស្មុគស្មាញ និងបុគ្គលិកមិនព្រមប្រើ៖
    • ធ្លាប់ទិញប្រព័ន្ធបរទេស ឬប្រព័ន្ធស្មុគស្មាញមកប្រើ តែបុគ្គលិកមិនចេះអង់គ្លេស រៀនមិនចេះ ហើយត្អូញត្អែរចង់ឈប់ពីការងារ រហូតដល់ត្រូវបោះបង់ចោលប្រព័ន្ធនោះ។
  3. ការបារម្ភរឿងដាច់អ៊ីនធឺណិត៖
    • នៅកម្ពុជា អ៊ីនធឺណិត និងចរន្តអគ្គិសនីអាចដាច់ជាយថាហេតុ។ ប្រសិនបើប្រព័ន្ធគាំងពេលអតិថិជនឈរតម្រង់ជួរចាំទិញ អាជីវកម្មនឹងខាតបង់ធ្ងន់ធ្ងរ។
  4. ការបារម្ភរឿងតម្លៃ និងការចំណាយឥតប្រយោជន៍៖
    • មិនចង់បង់លុយប្រចាំខែឥតប្រយោជន៍ ប្រសិនបើមិនឃើញលទ្ធផលជាក់ស្តែងថាជួយសន្សំលុយបានប៉ុន្មាន ឬជួយបង្កើនចំណូលបានកម្រិតណា។

2. រូបមន្តបើកកិច្ចសន្ទនាទាក់ទាញចិត្ត #

នៅពេលជួបម្ចាស់អាជីវកម្មលើកដំបូង សូមកុំចាប់ផ្តើមដោយនិយាយថា «ខ្ញុំមកលក់ប្រព័ន្ធគ្រប់គ្រងអាជីវកម្ម»។ ត្រូវចាប់ផ្តើមដោយការចោទសួរដែលធ្វើឱ្យពួកគាត់ភ្ញាក់ខ្លួន៖

3. ជំហានបង្ហាញគំរូផ្ទាល់រយៈពេល 3 នាទី #

ពេលធ្វើការបង្ហាញគំរូសាកល្បង សូមកុំដើរបង្ហាញគ្រប់ទំព័រនាំឱ្យធុញទ្រាន់។ សូមអនុវត្តតាម 3 ជំហានអស្ចារ្យនេះ៖

នាទីទី 1៖ បង្ហាញការលក់រហ័ស និងបាគង ខេអេចឃ្យូអរ ឌីណាមិក #

  • ស្កេនបាកូដទំនិញ 1 មុខ → អេក្រង់បង្ហាញតម្លៃ និងរូបភាពភ្លាមៗ។
  • ចុចប៊ូតុងគិតលុយ → កូដស្កេនបាគង ខេអេចឃ្យូអរ បង្ហាញឡើងភ្លាមៗជាមួយចំនួនទឹកប្រាក់សុក្រឹត។
  • ពេលស្កេនបង់ប្រាក់ជោគជ័យ → ម៉ាស៊ីនចេញវិក្កយបត្រភ្លាមៗ ហើយស្តុកក្នុងឃ្លាំងកាត់ដោយស្វ័យប្រវត្តិ។

នាទីទី 2៖ សាកល្បងផ្តាច់អ៊ីនធឺណិតផ្ទាល់ភ្នែក #

  • បិទសេវាអ៊ីនធឺណិត ឬដកខ្សែបណ្តាញចេញនៅចំពោះមុខអតិថិជន។
  • ចុចស្កេនលក់ និងចេញវិក្កយបត្របន្តទៀត → ប្រព័ន្ធនៅតែដំណើរការយ៉ាងរលូនឥតទាក់ទាល់។
  • បើកអ៊ីនធឺណិតឡើងវិញ → ប្រព័ន្ធធ្វើសមកាលកម្មទិន្នន័យចូលប្រព័ន្ធពពកស្វ័យប្រវត្តិ 100% គ្មានបាត់បង់សូម្បីតែ 1 សេន។
  • ផលប៉ះពាល់ផ្លូវចិត្ត៖ ម្ចាស់អាជីវកម្មនឹងមានទំនុកចិត្តខ្ពស់បំផុត ព្រោះដឹងថាហាងរបស់គាត់គ្មានថ្ងៃគាំងលក់មិនកើតឡើយ។

នាទីទី 3៖ បង្ហាញដំណឹងប្រាក់ចំណេញសុទ្ធលើតេឡេក្រាម #

  • ឱ្យម្ចាស់អាជីវកម្មបើកទូរស័ព្ទដៃមើលតេឡេក្រាម។
  • ប្រព័ន្ធស្វ័យប្រវត្តិនឹងផ្ញើរបាយការណ៍បិទវេនប្រចាំថ្ងៃភ្លាមៗ ដែលបង្ហាញពី៖
    1. ចំណូលសរុបប្រចាំថ្ងៃ
    2. ថ្លៃដើមទំនិញទិញចូល

    4. ប្រាក់ចំណេញសុទ្ធពិតប្រាកដដែលនៅសល់ក្នុងដៃ
  • ផលប៉ះពាល់ផ្លូវចិត្ត៖ ម្ចាស់អាជីវកម្មដឹងថា គាត់អាចដើរលេងក្រៅប្រទេស ឬសម្រាកនៅផ្ទះ ក៏នៅតែគ្រប់គ្រងលុយកាក់បាន 100%។
